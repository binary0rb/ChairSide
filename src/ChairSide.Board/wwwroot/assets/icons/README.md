# Procedure icons

The inline SVG procedure icons rendered by `wwwroot/board.js` are based on
Tabler Icons where an equivalent icon exists (search, microscope, moon,
thumb-up, bolt, dots, calendar, link, eye, phone). Icons with no Tabler
equivalent (forceps, impression tray, jackhammer) are custom drawings in the
same 24x24 stroke-2 outline style.

Tabler Icons are MIT licensed.

Source: https://github.com/tabler/tabler-icons
